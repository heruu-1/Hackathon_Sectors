# Hackathon Sectors Saham

Repository publik untuk proyek Hackathon Sectors Saham berbasis Next.js.

## Status

Dalam tahap awal pengembangan.

## Menjalankan secara lokal

Pastikan pnpm tersedia, lalu jalankan:

```bash
pnpm install
pnpm dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser. Halaman utama ada di `app/page.tsx`.
