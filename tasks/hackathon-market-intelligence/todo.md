# Checklist Tugas Implementasi RASI Market Intelligence

## Fase A — Fondasi dan pengaman

- [x] **A01**: Baseline Git, instruksi lokal, command, dan status runtime.
- [x] **A02**: Registry kemampuan API dan skema normalisasi.
- [x] **A03**: Tabel anggaran/penggunaan dan migrasinya.
- [x] **A04**: Transport Sectors bersama.
- [x] **A05**: Hubungkan provider utama dan wrapper lama ke transport.
- [x] **A06**: Hubungkan search, screener, dan fallback pasar.
- [x] **A07**: Perbaiki cache lease dan idempotensi.
- [x] **A08**: Normalisasi tanggal, harga, satuan, dan data kosong.
- [x] **Checkpoint A**: Pemeriksaan biaya, concurrency, dan kontrak lulus sebelum probe provider nyata.

## Fase B — Satu alur pasar hingga bukti

- [x] **B01**: Universe emiten dan metadata sektor.
- [x] **B02**: Service ringkasan pasar.
- [x] **B03**: Halaman pasar dan navigasinya.
- [x] **B04**: Discovery kandidat dari beberapa sumber (Two-Tier Scanner).
- [x] **B05**: Harga historis dan benchmark (Relative Strength).
- [x] **B06**: Arus asing dan agregasi broker.
- [x] **B07**: Berita, filing, dan aksi korporasi.
- [x] **B08**: Engine aturan R01–R04, R08–R10.
- [x] **B09**: Persistensi scan/snapshot.
- [x] **B10**: Radar dan detail bukti.
- [x] **Checkpoint B**: Alur pasar → radar → bukti bekerja dengan data nyata.

## Fase C — Fundamental, valuasi, dan kepemilikan

- [x] **C01**: Adapter kuartalan dan basis pelaporan.
- [x] **C02**: Perhitungan perubahan fundamental.
- [x] **C03**: Presentasi fundamental sesuai kelompok usaha.
- [x] **C04**: Peer universe dan rasio valuasi.
- [x] **C05**: Persentil, median, dan pembanding UI.
- [x] **C06**: Kepemilikan bulanan, free float, dan filing.
- [x] **C07**: Panel kepemilikan dan konteks risiko.
- [x] **C08**: Tambahkan R05–R07 pada brief dan screener.
- [x] **Checkpoint C**: Satu saham dapat dibaca dari transaksi hingga kondisi bisnis dan pembandingnya.
